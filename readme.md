# Amazon Prime Video Landing Page Clone

This project is a front-end clone of the Amazon Prime Video landing page, built using HTML and CSS. It aims to closely replicate the look, feel, and interactive experience of the official Prime Video homepage, with a focus on responsive design, interactive icons, and modern web development best practices.

---

## Features

- **Responsive Layout:**  
  The site uses CSS Flexbox to ensure that all sections, including navigation, hero banners, and content grids, adapt smoothly to different screen sizes and devices.

- **Interactive Navigation Bar:**  
  The navigation bar features the Prime Video logo, main navigation links (Home, Store, Live TV, Categories, Language), a search bar, and a user profile icon. Dropdown menus appear on hover for categories and language selection, enhancing usability.

- **Interactive Icons & Symbols:**  
  SVG and image-based icons are used throughout the navigation and content areas. Icons such as the user profile, search, and dropdown arrows respond visually to user interactions (hover, focus), providing immediate feedback and a dynamic user experience.

- **Hero & Promotional Sections:**  
  The hero section welcomes users with a bold headline, a brief description, and a call-to-action button, accompanied by a large promotional image. Additional sections highlight movie rentals and featured content, using visually engaging layouts.

- **Channel Showcase:**  
  A grid of channel logos and banners is presented, each with interactive hover effects (e.g., glowing box-shadows) to draw attention and invite user interaction.

- **Modern Styling:**  
  The color scheme mirrors Amazon Prime Video’s branding, with a dark background, white and blue accents, and clean, modern typography. Buttons and links are styled for clarity and accessibility.

## Key Implementation Details

- **HTML:**  
  Semantic HTML5 elements are used for structure and accessibility. Navigation, main content, and footer are clearly separated.

- **CSS:**  
  - Flexbox is used for layout and alignment.
  - Custom classes provide styling for navigation, dropdowns, buttons, and content sections.
  - Interactive effects (hover, focus) are achieved using transitions and box-shadows.
  - Responsive units (`vw`, `vh`, `%`) ensure adaptability to various screen sizes.

- **Interactive Icons:**  
  - Profile and search icons are styled as circular avatars or buttons.
  - Dropdown arrows and other symbols use SVG or PNG for crisp rendering.
  - All icons respond to user actions with color changes, shadows, or scaling effects.
